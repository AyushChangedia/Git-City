# assets

**`waternormals.jpg`** — the tiling water normal map from the
[three.js](https://github.com/mrdoob/three.js) examples
(`examples/textures/waternormals.jpg`), MIT licensed, copyright the three.js
authors.

It is committed here rather than hotlinked. Loading it from a CDN or from a
`raw.githubusercontent.com` URL would leave the water dependent on a third-party
host that can rate-limit, change paths, or send CORS headers that break a
canvas-backed texture — and it would fail on GitHub Pages exactly when the demo
is being looked at.
